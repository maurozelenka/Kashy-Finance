## 🛠️ Stack Tecnológico de Élite

Kashy ha sido diseñado bajo los más estrictos estándares de ingeniería de software, combinando velocidad, seguridad y una interfaz de usuario state-of-the-art.

*   **Core Engine**: [Python 3](https://www.python.org/) & [Flask Framework](https://flask.palletsprojects.com/)
*   **Persistencia Ultra-Rápida**: [Sirope](https://pypi.org/project/sirope/) & [Redis](https://redis.io/) NoSQL
*   **Seguridad Bancaria**: Encriptación AES-256 & Protocolo PSD2 Compliance
*   **Frontend Premium**: Tailwind CSS, Interactive 3D CSS Cuboids & Jinja2 Templates
*   **Infraestructura**: Despliegue continuo en [Render](https://render.com/) con dominio personalizado

## ✨ Características Destacadas

1.  **Consolidación Patrimonial**: Agregación de múltiples entidades financieras en una única interfaz cohesiva.
2.  **Visualización Inmersiva**: Gráficos interactivos en 3D para una comprensión inmediata de la evolución financiera.
3.  **Privacidad por Diseño**: Los datos están encriptados y el sistema opera bajo conexiones de solo lectura, garantizando seguridad absoluta.
4.  **Categorización Automática**: Motor inteligente de clasificación de transacciones para insights profundos de gasto.

## 💻 Configuración del Entorno Local

Si deseas ejecutar Kashy en tu máquina local:

```bash
# 1. Clonar el repositorio
git clone https://github.com/maurozelenka/Kashy-Finance.git

# 2. Configurar entorno virtual
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Instalar dependencias
pip install -r requirements.txt

# 4. Iniciar el servidor
python src/app.py
```

Accede a la plataforma en `http://127.0.0.1:5000/`
